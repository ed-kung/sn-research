\section{Tip-based learning}\label{sec_v4v}

We now consider our second hypothesis: that users learn from and respond to tip feedback by shifting their posting behavior towards better rewarded post types. 

\subsection{Model of tip-based learning}

We start by developing a model of learning from tip feedback. Because learning involves many unobservables, like users' priors, information sets, and sources of uncertainty, we aim to keep the model parsimonious. The purpose of the model is to illustrate how assumptions about the decision structure lead to testable predictions, rather than to deeply micro-found the assumptions.\footnote{In the appendix, we develop a more microfounded model and discuss how they map onto our assumptions here.}

We assume that users are learning about the expected rewards in territories. Let $j$ index a territory. The expected present value of the Poisson stream of zaps in territory $j$ is:
\begin{align}
V(q; \Theta_j) = \Theta_j v(q)  \label{eq_v4v_V}
\end{align}
where $v(q)$ is known, continuous, and strictly increasing in $q$. $\Theta_j$ is an unknown, territory-specific parameter which reflects how generously posts are rewarded in territory $j$, holding post quality fixed.

Let $\mathcal{I}_{it}$ denote user $i$'s information at time $t$, which includes previously observed tip rewards. Define $A_{ijt}$ and $\alpha_{ijt}$ as the expected value and the log expected value of $\Theta_{j}$ conditional on the user's information set:
\begin{align}
A_{ijt} = E\left[ \Theta_{j} \mid \mathcal{I}_{it} \right], ~ ~ \alpha_{ijt} = \ln A_{ijt}
\end{align}

Post ideas for territory $j$ arrive for user $i$ at rate $\gamma_{ij}$, and their quality and intrinsic motivation are distributed according to $f^{ij}(q,\epsilon) = f^{ij}_{\epsilon|q}(\epsilon|q)f^{ij}_q(q)$. As in Section \ref{sec_pay_to_post_model}, we assume that within each territory, $f^{ij}(q,\epsilon)$ satisfies log concavity and the monotone likelihood ratio property.

If a post idea for territory $j$ arrives for user $i$ at time $t$ with quality and intrinsic motivation $(q,\epsilon)$, the posting rule is post if:
\begin{align}
\alpha_{ijt} + \ln v(q) + \epsilon > \kappa_{jt}
\end{align}
where $\kappa_{jt} = \ln c_{jt}$ is the log posting cost in territory $j$ at time $t$.  The probability (over $q, \epsilon$) that the idea is posted is given by:
\begin{align}
P_{ijt} = \int S^{ij}_{\epsilon|q} \left( \kappa_{jt} - \alpha_{ijt} - \ln v(q) \mid q \right) f^{ij}_q(q) dq
\end{align}
which is decreasing in $\kappa_{jt}$ and increasing in $\alpha_{ijt}$. Thus, higher posting costs deter posting, but a greater expectation of tip rewards incentivizes posting. The instantaneous rate of user $i$ posting in territory $j$ at time $t$ is $\gamma_{ij} P_{ijt}$.

\subsection{Empirical specification}

To bring the model to the data, we model belief updating at a weekly frequency. This need not imply that users formally update their beliefs once a week, but it captures the idea that behavioral responses to tip feedback are gradual and that high-frequency variation in individual posting decisions is largely idiosyncratic. The temporal aggregation also permits territory-by-week fixed effects that absorb common changes in territory-level attention and posting incentives, allowing learning to be identified from variation in individual post histories. 

We also model users as updating their beliefs using tips that a post receives after 48 hours, $Z$. This keeps the model parsimonious, because $\ln Z$ is a noisy signal of $\theta_j + \ln v(q)$, and it allows us to abstract away from details about the timing of when posts receive their zaps.\footnote{To see this, we note that $E[Z] \propto V(q) = \Theta_jv(q)$, according to equations \eqref{eq_V} and \eqref{eq_v4v_V}. We can therefore write $Z = \Theta_j v(q) e^{\eta}$, or $\ln Z = \theta_j + \ln v(q) + \eta$, where $\eta$ is an i.i.d. residual arising from the idiosyncratic realizations of the Poisson zaps process.} We therefore assume that users update their beliefs according to their history of ``quality-adjusted zap signals'': $r = \ln Z - \ln v(q)$.

Let $\mathcal{I}_{iw}$ be user $i$'s information set at week $w$. Let $p$ index a post, sorted by timestamp, and let $i(p)$ be the user who made the post, $j(p)$ be the territory of the post, and $\tau(p)$ be the timestamp of the post. Let $\tau(w)$ be the timestamp of the start of a week. The information set available to user $i$ at the start of week $t$ is:
\begin{align}
\mathcal{I}_{iw} = \left\{ (Z_p, q_p):p\in \mathcal{P}_{iw} \right\}, ~ ~ \mathcal{P}_{iw} = \left\{ p: \tau(p) < \tau(w) - \text{48 hours} \right\}
\end{align}
In words, the user is able to observe signals for all posts made 48 hours before the start of the week.

We postulate the following reduced form specification for $\alpha_{ijt}$, the log of the user's posterior mean over $\Theta_j$ at the start of week $w$:
\begin{align}
\alpha_{ijw} &= b^0_{ij} + \beta \sum_{p \in \mathcal{P}_{iw}} K_{ijwp} \left[ \ln Z_p - \ln v(q_p) \right] \nonumber \\
& = b^0_{ij} + \beta \sum_{p \in \mathcal{P}_{iw}} K_{ijwp} r_{p} 
\end{align}
In words, the log of the user's posterior mean over $\Theta_j$ is a weighted sum of previously observed quality-adjusted zap signals, $r_p : p\in \mathcal{P}_{iw}$. This specification nests standard models of learning like conjugate-normal Bayesian updating, but it is flexible enough to allow for effects like attention decay and social proximity in learning. For example, suppose we assume that users pay more attention to recent signals and that they only learn from their own signals. Then, we could specify the kernel weights as:
\begin{align}
K_{ijwp} \propto e^{-(\tau(w) - \tau(p))/\sigma} 1 \left[ j(p)=j, ~ i(p)=i \right]
\end{align}
However, we need not specify the weights in this manner, and in practice we try different assumptions about the information environment.

Now, let $E \left[ N_{ijw} \mid \mathcal{I}_{iw} \right]$ be the expected number of posts user $i$ will make in territory $j$ in week $t$, conditional in the information set $\mathcal{I}_{iw}$. Under our beliefs model, the exact form is equal to:
\begin{align}
E \left[ N_{ijw} \mid \mathcal{I}_{iw} \right] = \gamma_{ij} \int_{\tau(w)}^{\tau(w+1)} \int S_{\epsilon|q}^{ij} \left( \kappa_{jt} - \alpha_{ijw} - \ln v(q) \mid q \right) f_q^{ij}(q) dq dt \label{eq_v4v_EN}
\end{align}
This expression shows that the number of posts in week $w$ is expected to depend on:
\begin{itemize}
\item User-by-territory effects; namely, a user-territory-specific arrival rate of post ideas, $\gamma_{ij}$, and user-territory-specific distribution of post quality and intrinsic motivation, $f^{ij}(q,\epsilon)$. This captures permanent differences in users' preferences and ability to post in different territories.
\item Territory-by-time effects; namely, the posting cost of the territory at any time $t$, $\kappa_{jt}$. In the reduced form, territory-by-time effects could also capture topic-specific trends, such as those driven by news cycles, that are not user-specific.
\item The weighted sum of previously observed quality-adjusted zap signals, $\alpha_{ijw}$. Higher past signals will lead to a higher expected number of posts in the week.
\end{itemize}
To turn this into a reduced form estimating equation, we model the number of posts with a fixed-effects Poisson model:
\begin{align}
& N_{ijw} \mid \mathcal{I}_{iw} \sim \text{Poisson}(\mu_{ijw}) \nonumber \\
& \ln \mu_{ijw} = \beta \sum_{p \in \mathcal{P}_{iw}} K_{ijwp} r_{p} + \xi_{ij} + \zeta_{jw} + \nu_{iw} \label{eq_v4v_estimator}
\end{align}
User-by-territory fixed effects, $\xi_{ij}$, capture user-specific preferences and tendencies to post in specific territories. Territory-by-week fixed effects, $\zeta_{jw}$, capture territory-specific time trends as well as variation in posting costs. We also add user-by-week fixed effects $\nu_{iw}$ to capture changing non-territory-specific user motivation over time. 

A few comments on identification. First, identification of learning comes from user-level variation in territory-specific signals. If all users had access to the same signals and formed the same expectations about territory rewards, then this would be fully absorbed into $\zeta_{jw}$. Second, the main threat to identification comes from user-by-territory specific time trends. For example, if users have time-varying territory-specific ability, then past observed signals may reflect growing ability, which is also correlated with subsequent posting. For the purposes of this paper, we do not really care whether the learning is about territory rewards or about territory-specific user ability; in either case the result is that tip feedback affects user posting decisions. So if users are learning from tip feedback about their own ability, then we do not consider that a threat to identification. A correlation between past signals and subsequent posting is only spurious if the subsequent posting would have happened regardless of what the prior tip feedback was, so that the correlation only exists as a coincidence. An example of this would be a news cycle that generates high rewards for specific topics, but that only some users are heavily interested in posting about. To the extent that the effect of the news cycle is not captured in $\ln(q)$, it would show up in the quality-adjusted zap signal and create a correlation between the signals and the posting behavior, but because the users are inherently interested in posting about the topic, they would have posted regardless of the signals. Without purely exogenous variation in signals, we cannot rule out such threats to identification. Our results should therefore be interpreted as evidence consistent with learning rather than a tightly identified causal estimate of learning.
